How the value is fitted

implied value = exp(fitted log market cap) × launch odds

Fitted log market cap is a ridge regression (λ = 5) of log market cap on log TVL, log age in days, 7-day TVL growth (clamped to −30…+60%) and log chain count, plus one effect per category, trained at run time on the protocols whose token already trades. Launch odds are the smoothed share of comparable protocols that already record a token — the protocol's age bucket blended with its category, each shrunk toward the global share. The board ranks pre-token protocols only; the ones whose token already trades are listed separately, at the market's own value.

The fit is noisy — market caps vary widely around TVL — so treat every implied value as an order of magnitude, not a price target. “Records no token” means the snapshot's DefiLlama record carries no token for the protocol; it is not proof that none exists. This board does not predict whether or when a token is issued.
